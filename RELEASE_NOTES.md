# podterm-rs v0.4.3 — Windows 11 preview

This is a **test release**, not a confirmed Windows-stable version. Linux behavior remains unchanged from v0.4.2.

## Changes

- Native Windows 11 terminal compilation with `crossterm`.
- Windows `mpv` named-pipe IPC instead of Unix sockets; bounded response polling.
- Per-user Windows library, history and offline downloads in `%LOCALAPPDATA%\podterm`.
- Windows-safe JSON overwrite so listening progress persists across runs.
- Windows ZIP generated by GitHub Actions, containing the EXE, Windows instructions and license.
- `--doctor` verifies installed `mpv` and `curl`.
- Smooth playback priority: standard `mpv` buffers remain the default.

## Requirements

Windows 11, Windows Terminal, `mpv` (separate installation), `curl.exe` (normally preinstalled).
Linux remains supported with `mpv` and `curl`.

## Testing needed

Confirm the actual `.exe` launches on Windows 11, plays audio, handles pause/seek, saves progress, searches feeds and downloads an episode. CI passing means the code builds and tests pass, but is **not** a full audio playback test.
